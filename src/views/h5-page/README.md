# H5 模板配置规则

本手册以当前 `src/views/h5-page` 生产页面逻辑为准，面向模板配置、商品配置和上线验收人员。它说明各 H5 页面实际读取哪些图层属性、用户可以修改什么，以及保存和跳转需要哪些参数。

## 配置前必读

H5 不依赖图层名称、图片文件名或画布上的原始文案判断业务图层，只读取图层“属性”中保存的图片描述、文字描述、图片用途和素材组绑定。

| 规则 | 实际结果 |
| --- | --- |
| 属性值精确匹配 | `姓`、`姓氏`和`用户姓氏`是不同标记，不能混用。 |
| 图层名不能代替业务属性 | 把图层改名为“背景图”或“原图替换”不会生效，必须在图层属性中配置。 |
| 未配置业务属性的图层保持模板状态 | 固定装饰图片和固定文字通常不需要填写描述。 |
| 同一标记可以配置多个图层 | 图片或文字替换通常会作用于全部匹配图层；音乐款的多个文字图层除外，详见对应章节。 |
| 替换不会改变图层结构 | 图层位置、外框、旋转、层级和锁定状态保持不变。 |
| 锁定不阻止 H5 业务替换 | H5 可以替换已锁定的目标图片和文字。 |
| 配置需要保存两次 | 图层属性中点击“保存配置”后，还要点击编辑器“立即保存”保存整个模板。 |
| 隐藏图片按需加载 | 初始隐藏的图片不请求资源，第一次显示时才加载。模板仍需保留有效图片 URL。 |
| H5 画布固定缩放 | 画布保持模板宽高比并适配页面宽度，用户不能改变画布缩放比例。 |

### 图片用途的可选值

编辑器中的“图片用途”与 H5 内部标记对应如下：

| 编辑器选项 | 内部值 | 当前 H5 用途 |
| --- | --- | --- |
| 普通图片 | 空 | 固定图片或仅靠图片描述识别的图片。 |
| 背景图 | `background` | 诗词页可切换背景。 |
| AI主题背景图 | `ai-theme-background` | 人像款可切换 AI 主题背景。 |
| 遮罩图 | `mask` | 成品遮挡和打印区域相关输出。 |
| AI 可变图 | `ai-variable` | 诗词页、人像款的 AI 主图替换目标。 |

### 图片绑定素材组

当前只有**人像款定制页**会把模板内的素材组绑定显示为用户可选素材。需要使用该能力时，在目标图片的“图片属性 → 业务属性 → 绑定素材组”中选择素材组，然后点击“保存配置”。

- 一个图片图层只能绑定一个素材组，同一素材组可以绑定多个图片图层。
- H5 使用素材组 ID 请求图片，素材组名称只用于编辑器核对。
- 页面会读取模板内所有图片图层的素材组绑定，并合并各组的候选素材。
- 用户选择某个素材时，只替换绑定到该素材所属组的图片图层；同组多个图层会一起替换。
- 各素材组的第一批素材最多读取 1000 张；同组内相同 URL 会去重。
- 页面初次加载会自动应用候选列表中的第一张素材。
- 绑定不会立即改变编辑器画布上的图片，也不会改变图层位置、尺寸或层级。
- 素材组已删除、为空或没有有效图片时，人像款无法完成提交，应在上线前重新绑定并验收。

| --- | --- | --- |

| 十二生肖 | `#/h5-page/chinese-zodiac` | 十二生肖图片描述；文字描述 `年`。 |
| 原图定制 | `#/h5-page/original-customization`，兼容别名 `original-image` | 图片描述 `原图替换`。 |

所有页面都必须通过查询参数传入正确的 `templateId`。模板 ID 必须是后台模板记录的正整数，不能使用商品 ID、SKU ID 或用户设计 ID 代替。

## 页面公共参数

| 参数 | 是否必需 | 用途 |
| --- | --- | --- |
| `templateId` | 是 | 加载后台模板并作为用户设计的来源模板。 |
| `redirectPath` | 完整购买流程必需 | 保存成功后通过 `wx.miniProgram.redirectTo` 进入的小程序页面路径。 |
| `partnerId` | 按业务 | 作为模板、素材和保存接口的分销商上下文。 |
| `skuId` | 按业务 | 查询模板时携带，并在保存用户设计时写入。 |
| `designName` | 否 | 覆盖页面默认的用户设计名称。 |
| `token` / `authorization` / `Authorization` | 按接口鉴权 | 初始化 H5 customer 接口凭证；页面读取后会从地址栏移除并缓存到当前会话。 |

保存成功后，H5 会在 `redirectPath` 中追加：

- `designId`：保存接口返回的用户设计 ID；缺失时页面报错且不跳转。
- `source=SERIES`：原路径未提供 `source` 时自动补充。
- `previewImgUrl`：优先使用整张预览图地址，无预览图时使用产品图地址。

除 H5 内部参数外，地址中的其他业务参数会原样追加到跳转路径；如果 `redirectPath` 已有同名参数，则保留路径中的原值。

## 百家姓配置

### 当前页面行为

当前百家姓页面只显示一个“姓氏（必填）”输入框，不显示名字输入框。

| 模板图层 | 属性中填写 | H5 行为 |
| --- | --- | --- |
| 姓氏文字 | 文字描述 `姓` | 模板第一个 `姓` 图层的原文进入输入框；用户输入会同步替换所有 `姓` 图层。 |
| 名字文字 | 文字描述 `名` | 不生成输入框，保留模板原文；切换字体时会与 `姓` 图层一起更新字体。 |

姓氏为空时“立即购买”不可用。未配置 H5 输入规则时，姓氏仍使用页面兜底限制：启用规则、禁止换行、最多一行、最大内容长度为 4，即最多输入两个中文字符。模板已配置输入规则时，以模板中第一个 `姓` 图层的规则为准。

页面目前提供锦书、宋体、黑体和行书四种固定字体。切换字体会更新所有描述为 `姓` 或 `名` 的文字；模板字体若不在这四种字体中，初始状态不会选中任何字体按钮。

### 百家姓验收

1. 页面只出现姓氏输入框，模板中的名字保持原文。
2. 修改姓氏后，所有 `姓` 图层同步更新，其他文字不变。
3. 清空姓氏后不能提交。
4. 依次切换四种字体，`姓` 和 `名` 图层字体同步变化，位置不应明显偏移。
5. 复姓输入长度和单行显示符合第一个 `姓` 图层的 H5 输入规则。

## 十二生肖配置

### 生肖图片

每个生肖使用独立图片图层，并在图片描述中分别填写：

| `鼠` | `牛` | `虎` | `兔` | `龙` | `蛇` |
| --- | --- | --- | --- | --- | --- |
| `马` | `羊` | `猴` | `鸡` | `狗` | `猪` |

页面初次打开默认选中 `鼠`。选择生肖时，图片描述等于当前生肖的图层显示，**所有填写了其他图片描述的图层都会隐藏**。因此固定背景、遮罩、边框和装饰图片不要填写图片描述；否则它们会在生肖切换时被当作互斥图片隐藏。

如果模板没有 `鼠` 图层，默认状态没有生肖主图。如果同一生肖配置了多个图层，选择该生肖时这些图层会一起显示。初次加载只请求当前可见图片，其他生肖图在第一次选择时才加载并复用缓存。

### 年份文字

| 模板图层 | 属性中填写 | H5 行为 |
| --- | --- | --- |
| 年份文字 | 文字描述 `年` | 第一个 `年` 图层的原文进入输入框；输入会同步替换所有 `年` 图层。 |

当前页面只提供一个年份输入框，不提供月、日输入框。配置 `月` 或 `日` 不会生成输入项，它们会保持模板原文。

第一个 `年` 图层提供输入规则。未配置时不启用过滤，只携带最大内容长度 20 的默认值；因为规则未启用，该长度不会实际限制输入。虽然输入框使用数字键盘提示，页面本身并未强制只输入数字，如需限制内容应结合模板规则和业务验收。

### 十二生肖验收

1. 初次打开显示鼠图层，其他生肖图不显示。
2. 依次切换十二生肖，每次只显示当前生肖图层。
3. 固定背景、遮罩和装饰图片始终显示，不受生肖切换影响。
4. 页面只出现年份输入框，修改后所有 `年` 图层同步更新。
5. `月`、`日`及其他固定文字保持模板原文。

## 原图定制配置

| 模板图层 | 属性中填写 | H5 行为 |
| --- | --- | --- |
| 用户上传图片 | 图片描述 `原图替换` | 上传、裁剪并替换所有匹配图层。 |

页面使用第一个 `原图替换` 图层显示初始预览，并以该图层的宽高比作为裁剪比例。用户可以在裁剪页移动、缩放、旋转图片；确认后才上传并替换。

裁剪结果会以 `contain` 方式完整放入所有 `原图替换` 图层，保留各图层原有外框。多个目标图层比例不同时仍共用第一目标的裁剪结果，因此建议所有目标框使用相同比例。

原图定制只提供图片上传，不提供文字输入。即使模板配置 `文本替换`，文字也不会被用户修改。没有配置图片目标时页面仍可进入保存流程，但上传按钮不会执行替换，因此上线模板必须配置并验收 `原图替换`。

## 音乐款定制配置

| 模板图层 | 属性中填写 | H5 行为 |
| --- | --- | --- |
| 用户上传图片 | 图片描述 `原图替换` | 用户可拍照或从相册选图，裁剪后替换全部匹配图层。 |
| 用户修改文字 | 文字描述 `文本替换` | 为每个匹配文字图层生成输入框并实时替换。 |

页面加载后，只要存在 `原图替换` 且用户尚未上传图片，就会自动打开“相机拍摄 / 相册选取”面板。裁剪比例、替换方式和多图层注意事项与原图定制相同。

模板只有一个 `文本替换` 图层时，页面显示一个无编号输入框。存在多个 `文本替换` 图层时，按模板文档顺序显示“文本1”“文本2”……，每个输入框只修改对应图层，不会同步覆盖其他编号文字。每个图层独立读取自己的 H5 输入规则。

竖排文字的输入框优先读取模板文档原文，不会把画布为了竖排渲染产生的换行带入输入框。

## 诗词定制配置

### AI 主图

主图满足下列任一条件即可成为替换目标：

| 配置位置 | 可用值 |
| --- | --- |
| 图片用途 | `AI 可变图` |
| 图片描述 | `诗词配图`、`AI主题`、`原图替换`、`原图定制` |

同时满足多个条件的同一图层只会替换一次。配置多个目标时，切换或生成 AI 主题会一起替换，通常只应标记一个主图。

当前页面主图固定使用 `contain` 完整显示；“完整显示 / 填满画面”的高级设置未开放给用户。模板应使用构图居中、主体周围有适当留白的图片框和主题图。

页面可通过 `imageUrl` 接收当前主题图；通过 `aiSubjectIds` 加载可继续生成的 AI 主题。没有 `imageUrl` 时会自动打开 AI 主题选择流程：一个主题时直接进入上传来源，多个主题时先选择主题。生成过程中用户需上传或拍摄人像、裁剪，并等待 AI 任务完成。

### 诗词背景

需要随主题切换的背景图片，必须把图片用途设置为 `背景图`。只填写图片描述“背景”不会生效。

背景候选优先从所选 AI 主题配置读取，也兼容路由参数 `background_img_urls`、`backgroundImages`、`backgroundImageUrls`、`backgroundImageUrl`。切换主主题时会自动选中并应用该主题的第一张背景。背景始终使用 `cover` 填满原背景框。

### 可定制文字

诗词页会为每一种非空文字描述生成一个输入项。相同描述只生成一个输入项，并同步替换所有同描述文字。

| 文字描述 | 页面名称 |
| --- | --- |
| `文本替换`、`文案替换` | 诗词内容 |
| `主标题` | 诗词标题 |
| `副标题` | 副标题 |
| `落款` | 落款 |
| 其他非空描述 | 直接显示该描述 |

启用 H5 输入规则后，页面根据规则决定单行或多行控件。未启用规则时，描述包含“诗词”“正文”“内容”或“文案”的字段默认使用多行输入框，其他字段使用单行输入框。

## 人像款定制配置

人像款复用诗词页的 AI 主题流程，但第二个页签是“素材组”，不生成文字输入项。模板需要同时关注 AI 主图、AI 主题背景和素材组图片。

### AI 人像主图

| 配置位置 | 可用值 |
| --- | --- |
| 图片用途 | `AI 可变图` |
| 图片描述 | `人像替换`、`人像定制`、`AI主题`、`原图替换`、`原图定制` |

AI 主题选择、上传裁剪和生成流程与诗词页相同。多个目标会一起被生成结果替换，图片使用 `contain` 完整显示。

### AI 主题背景

人像款可切换背景必须把图片用途设置为 `AI主题背景图`。用途为普通 `背景图` 的图层不会成为人像款的背景替换目标。候选来源与诗词页一致，替换时使用 `cover`。

### 人像素材组

至少为一个图片图层绑定有效且非空的素材组。页面会合并模板中的全部绑定组，初次进入自动应用候选列表第一张素材；用户选择素材时，仅替换该素材所属组绑定的图层，并使用 `contain` 完整显示。

当前提交条件要求页面已读取到候选素材，并且模板存在对应绑定图层。配置了 `aiSubjectIds` 时，还必须先上传人像并生成 AI 定制效果。未满足条件时“立即购买”保持主色且可点击，点击后会在按钮上方提示需要完成的操作。

### 人像文字

当前人像款不显示文案定制页签，也不会为任何文字描述生成输入框。模板中的文字全部保持原文；不要把诗词页的 `文本替换`、`主标题`等规则套用到人像款。

## 通用文字输入规则

当前会读取文字输入规则的页面包括百家姓的 `姓`、生肖的 `年`、音乐款的 `文本替换`和诗词页的全部带描述文字。原图定制和人像款不生成文字输入项。

只有打开“启用 H5 用户输入”后，字符范围、符号、换行、长度和行数限制才会执行。中文及非 ASCII 字符计 2，ASCII 字符计 1，换行符不计入总长度。规则执行顺序为：

1. 统一换行并按配置移除用户主动换行。
2. 执行仅英文限制。
3. 执行符号和 Emoji 限制。
4. 执行最大内容长度。
5. 按每行最大内容自动换行。
6. 截取最大行数。

### 符号、标点和 Emoji

当前实现中“支持符号和 Emoji”关闭时，**普通标点仍会保留**，Emoji 及货币、数学等 Unicode 符号会被过滤。这一点与“只保留文字、数字和空格”的界面提示不同，配置和验收应以实际结果为准。

| 配置 | 实际输入结果 |
| --- | --- |
| 未启用 H5 用户输入 | 不执行任何过滤或长度限制，完整保留输入。 |
| 启用，符号开关关闭 | 保留文字、数字、空白和标点；过滤 Emoji 及其他符号类别字符。 |
| 启用，符号开关开启 | 保留文字、标点、特殊符号和 Emoji，再执行长度与行数限制。 |
| 仅支持英文，符号开关关闭 | 先保留 ASCII 可打印字符，再过滤其中非标点符号；中文和 Emoji 被移除。 |
| 仅支持英文，符号开关开启 | 保留 ASCII 可打印字符；中文和 Emoji 被移除。 |

例如输入 `中文 A1!😀`：符号开关关闭时得到 `中文 A1!`，开启时完整保留。

### 单行适配

姓氏、日期和短标题不希望换行时，建议选择“单行适配”。它会保持模板文字区域宽度和中心点，先使用模板原字号；内容放不下时缩小到配置的最小字号，仍放不下时允许超出区域，不裁切也不换行。内容变短后会恢复模板原字号。

| 配置项 | 百家姓 `姓` 建议值 |
| --- | --- |
| 显示方式 | `单行适配` |
| 最大内容长度 | `4`，可输入“欧阳”两个中文 |
| 最小字号 | 按模板效果填写；不填时默认为模板字号的 60% |

单行适配会自动关闭主动换行、固定最大行数为 1，并隐藏每行长度和最大行数配置，无需重复填写。

### 仅支持竖行

开启“仅支持竖行”后，H5 会移除用户换行并强制文字从上到下单列展示，不换到第二列。此模式只读取最大内容长度，不使用每行最大内容、最大行数或最小字号。

例如最多允许 4 个中文时，最大内容长度填写 `8`。竖排模板原文中的渲染换行不会显示在 H5 输入框内。

## 背景、遮罩和打印区域

### 固定背景与业务背景

固定背景可以保持普通图片且不填写图片描述。只有需要让用户切换时才配置业务用途：诗词页用 `背景图`，人像款用 `AI主题背景图`。背景建议铺满画板、放在底层、锁定并开启点击穿透。

### 遮罩图

生产遮罩应把图片用途设置为 `遮罩图`。遮罩不会成为普通图片替换目标，主要用于成品遮挡关系和输出控制。

### 打印区域与保存图片

需要产品图时，应使用编辑器画布工具创建真正的打印区域，或通过遮罩识别后手动调整。不要新建普通矩形并只把图层名改成“打印区域”。

| 输出 | 生成条件 | 范围 | 背景 | 遮罩 |
| --- | --- | --- | --- | --- |
| 预览图 `previewImgUrl` | 每次保存 | 整个画板 | 包含 | 包含 |
| 产品图 `productImgUrl` | 模板存在打印区域 | 打印区域 | 不包含 | 不包含 |

H5 保存时先导出当前编辑器 JSON，再上传 PNG 预览图；存在打印区域时额外上传 PNG 产品图，最后创建用户设计。保存 DTO 包含 `content`、`designName`、`previewImgUrl`、可选 `productImgUrl`、可选 `skuId` 和 `templateId`。

## 通用配置流程

1. 在编辑器中打开正确的后台模板。
2. 确认画板尺寸、图层顺序、图片外框和打印区域。
3. 根据目标 H5 页面，在每个业务图层的“属性”中配置图片描述、文字描述、图片用途或素材组。
4. 对每个图层点击“保存配置”。
5. 点击编辑器“立即保存”，把完整模板保存到后台。
6. 使用对应 H5 路由、正确的 `templateId` 和业务参数打开页面。
7. 按本手册的页面验收项完成输入、切图、保存和小程序跳转测试。

## 上线验收清单

| 检查项 | 合格标准 |
| --- | --- |
| 页面类型 | 商品配置的 H5 路由与模板业务类型一致。 |
| 模板加载 | `templateId` 为正整数，页面不提示缺少 ID、模板内容或鉴权失败。 |
| 画布显示 | 宽高比、位置、尺寸和层级与编辑器一致，无空白、裁切或异常闪烁。 |
| 固定图片 | 固定背景、遮罩、边框和装饰没有误填会触发业务切换的描述。 |
| 隐藏图片 | 首屏不请求隐藏图片，第一次切换后能正常加载。 |
| 文字输入 | 页面实际存在的输入项数量正确，过滤、换行、字号和竖排符合规则。 |
| 图片替换 | 替换目标完整且没有误伤，裁剪比例、`contain` / `cover` 效果符合预期。 |
| 人像素材 | 每个素材组选项只替换对应绑定图层，第一张默认素材正确，空组不会上线。 |
| AI 主题 | 主题 ID、主图、主题背景及生成流程可用，超时或接口失败有明确提示。 |
| 打印输出 | 预览图包含背景和遮罩；产品图只包含打印区域且排除背景和遮罩。 |
| 保存跳转 | `redirectPath` 是合法小程序路径；保存返回 `designId` 后使用 `redirectTo` 进入订单页。 |

## 常见配置错误

| 现象 | 优先检查 |
| --- | --- |
| 输入文字后画布不变 | 是否只改了图层名；文字描述是否精确匹配；当前页面是否真的提供该输入项。 |
| 百家姓没有名字输入框 | 当前实现只开放 `姓` 输入，`名`保持模板原文，这是预期行为。 |
| 生肖切换后背景或装饰消失 | 固定图片是否误填了图片描述；生肖页会隐藏所有描述不等于当前生肖的图片。 |
| 生肖没有月、日输入框 | 当前实现只读取文字描述 `年`，`月`和`日`不会生成输入项。 |
| 原图或音乐款无法上传替换 | 是否存在图片描述精确为 `原图替换` 的图层。 |
| 音乐款文字数量不对 | 有几个文字需要独立输入，就配置几个描述为 `文本替换` 的图层，并检查模板顺序。 |
| 诗词页没有主图可替换 | 主图是否配置为 `AI 可变图`，或图片描述是否为允许值之一。 |
| 诗词页没有背景可选 | 模板用途是否为 `背景图`，且 AI 主题或路由是否提供有效背景候选。 |
| 人像款背景不变化 | 人像款要求用途为 `AI主题背景图`，普通 `背景图`不会匹配。 |
| 人像款没有文案输入 | 当前人像款使用素材组页签，不生成文字输入，这是预期行为。 |
| 人像款点击“立即购买”后出现提示 | 按提示检查 AI 人像是否已生成、是否绑定至少一个有效非空素材组、素材接口是否成功、绑定图层是否仍存在。 |
| 符号关闭后标点仍保留 | 当前规则会保留 Unicode 标点，只过滤 Emoji 和其他符号类别字符。 |
| 保存后没有产品图 | 模板是否通过画布工具创建了真正的打印区域。 |
| 保存后不进入订单页 | 是否传入合法 `redirectPath`，当前是否在微信小程序 web-view 中，保存响应是否包含 `designId`。 |
