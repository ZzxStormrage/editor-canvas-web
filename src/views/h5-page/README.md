# H5 模板配置规则

本手册面向模板配置和运维人员，只说明 H5 页面如何识别模板图层、用户操作会修改哪些内容，以及上线前应如何验收。

## 配置前必读

H5 页面不依赖图层名称、图片文件名或画布上原有的文字。页面只读取图层“属性”中保存的图片描述、文字描述和图片用途。

| 规则 | 运维需要理解的结果 |
| --- | --- |
| 描述采用精确匹配 | `姓`、`姓氏`和`用户姓氏`是三个不同的标记，不能混用。 |
| 相同描述可配置多个图层 | 用户修改一次时，所有相同描述的图层会同时更新。 |
| 未配置描述的图层保持原样 | 普通装饰图片和固定文字不需要添加描述。 |
| 替换图片不改变图层结构 | 图层的位置、显示尺寸、旋转、层级和锁定状态保持不变。 |
| 图层锁定不等于禁止业务替换 | H5 仍可以替换已锁定的业务图片和文字。 |
| 属性需要单独保存 | 在图层属性中点击“保存配置”后，还要保存整个模板。 |
| 绑定素材组使用素材组 ID | 图片属性会保存素材组 ID 和名称；H5 以 ID 请求候选素材，名称只用于核对。 |

### 图片绑定素材组

需要让 H5 用户从指定素材范围内选择图片时，在目标图片图层的“图片属性 → 业务属性”中选择
“绑定素材组”。绑定后属性卡片会显示素材组名称、ID、图片数量和部分预览，确认无误后点击
“保存配置”。

一个图片图层只能绑定一个素材组。同一个素材组可以绑定到多个图片图层。绑定操作不会立刻
替换画布图片，也不会改变图层位置、尺寸或层级；它只告诉 H5 应该读取哪一组候选素材。

素材组被后台删除或没有随初始化数据传入时，编辑器会保留原绑定并标记为“当前不可用”。运维
应重新选择有效素材组，避免 H5 无法提供候选图片。

## 页面与模板对照

| H5 页面 | 路由 | 模板的核心标记 |
| --- | --- | --- |
| 百家姓 | `#/h5-page/hundred-family-surnames` | 文字描述 `姓`、`名` |
| 十二生肖 | `#/h5-page/chinese-zodiac` | 文字描述 `年`、`月`、`日`；图片描述为十二生肖 |
| 原图定制 | `#/h5-page/original-customization` | 图片描述 `原图替换`；文字描述 `文本替换` |
| 音乐款定制 | `#/h5-page/music-customization` | 图片描述 `原图替换`；文字描述 `文本替换` |
| 诗词定制 | `#/h5-page/poetry-customization` | 可替换主图、背景图和带描述的文字 |
| 人像款定制 | `#/h5-page/portrait-customization` | 可替换人像、背景图和带描述的文字 |

所有页面都必须通过地址传入正确的 `templateId`。模板 ID 必须是后台模板记录的正整数 ID，不能使用商品 ID、SKU ID 或用户设计 ID 代替。

## 百家姓配置

### 必须配置的图层

| 模板图层 | 属性中填写 | H5 页面的行为 |
| --- | --- | --- |
| 姓氏文字 | 文字描述 `姓` | “姓氏”输入框的内容会替换这个文字图层。 |
| 名字文字 | 文字描述 `名` | “名字”输入框的内容会替换这个文字图层。 |

姓氏是必填项，名字是选填项。模板加载后，页面会把第一个 `姓`和 `名`图层中的原文字带入输入框。

用户切换字体时，所有描述为 `姓`或 `名`的文字都会使用同一字体。建议姓和名使用两个独立文字图层，不要合并成“姓名”一个图层。

### 百家姓验收

1. 只修改姓氏，画布中只有 `姓` 图层改变。
2. 只修改名字，画布中只有 `名` 图层改变。
3. 切换字体，姓和名同时更换字体，位置不应明显偏移。
4. 清空名字后仍可正常保存；清空姓氏后不能提交。

## 十二生肖配置

### 生肖图片

每个生肖必须使用独立的图片图层，图片描述分别填写：

| `鼠` | `牛` | `虎` | `兔` | `龙` | `蛇` |
| --- | --- | --- | --- | --- | --- |
| `马` | `羊` | `猴` | `鸡` | `狗` | `猪` |

页面初次打开时默认选中 `鼠`。用户选择某个生肖后，页面只显示图片描述与当前生肖一致的图层，其他已配置生肖描述的图层会被隐藏。

如果模板没有 `鼠` 图层，默认状态下会没有生肖主图。如果同一生肖配置了多个图层，选中该生肖时这些图层会一起显示。

### 出生日期文字

| 模板图层 | 属性中填写 | H5 页面的行为 |
| --- | --- | --- |
| 年份文字 | 文字描述 `年` | “年”输入框替换该文字。 |
| 月份文字 | 文字描述 `月` | “月”输入框替换该文字。 |
| 日期文字 | 文字描述 `日` | “日”输入框替换该文字。 |

不要填写“年份”、“月份”或“日期”。页面只识别单个汉字 `年`、`月`、`日`。模板加载后，输入框会先显示对应图层的原文字。

`年`、`月`、`日`会分别读取各自文字图层中的 H5 用户输入规则。三个图层可以使用不同的最大内容长度、英文限制和符号限制；页面不会用其中一个图层的规则覆盖另外两个图层。

### 十二生肖验收

1. 初次打开时显示鼠的图片。
2. 依次切换十二生肖，每次只显示当前生肖图层。
3. 分别修改年、月、日，三类文字图层各自更新。
4. 背景、遮罩和装饰图层在切换生肖时保持不变。

## 原图定制配置

| 模板图层 | 属性中填写 | H5 页面的行为 |
| --- | --- | --- |
| 用户可上传的图片 | 图片描述 `原图替换` | “上传图片”替换该图层的图片资源。 |
| 用户可修改的文字 | 文字描述 `文本替换` | 文字输入框实时替换该图层文字。 |

页面会使用第一个 `原图替换` 图层作为初始图片预览，但用户上传后，所有图片描述为 `原图替换` 的图层都会被替换。

图片替换时采用“完整显示”方式，图片会等比缩放到原有图层范围内。请在模板中预留合适的图片框比例。

## 音乐款定制配置

音乐款定制与原图定制使用相同的模板标记：

| 模板图层 | 属性中填写 | H5 页面的行为 |
| --- | --- | --- |
| 用户可上传的图片 | 图片描述 `原图替换` | 用户可从手机相册选择图片，或使用摄像头拍摄。 |
| 用户可修改的文字 | 文字描述 `文本替换` | 文字输入框实时替换该图层文字。 |

页面加载后，如果已配置 `原图替换` 且用户还没有上传图片，页面底部会自动打开图片来源选择面板。这个面板是音乐款页面与原图定制页面的主要交互差异，模板标记本身没有差异。

## 诗词定制配置

### 可替换主图

主图可以使用下列任意一种方式标记：

| 配置位置 | 可用值 |
| --- | --- |
| 图片用途 | `AI 可变图` |
| 图片描述 | `诗词配图`、`AI主题`、`原图替换`或`原图定制` |

如果多个图片图层使用了上述标记，用户切换 AI 主题时这些图层会一起替换。通常只应标记一个主图图层。

用户可以选择“完整显示”或“填满画面”。运维应使用构图居中、主体周围有适当留白的原图，避免用户选择填满时裁掉主体。

### 背景图

需要被用户切换的背景图，必须将图片用途设置为 `背景图`。只修改图片描述为“背景”不会生效。

候选主题图和背景图由商品页面或小程序传入。模板运维人员负责配置“哪个图层可以被替换”，不需要把所有候选图片预先放入模板。

### 可定制文字

诗词页会为每一种非空的文字描述生成一个输入项。运维可以按需配置多个文字图层。

| 文字描述 | H5 页面显示的名称 | 适合的内容 |
| --- | --- | --- |
| `文本替换` | 诗词内容 | 通用诗词或文案 |
| `文案替换` | 诗词内容 | 通用诗词或文案 |
| `主标题` | 诗词标题 | 主标题 |
| `副标题` | 副标题 | 副标题 |
| `落款` | 落款 | 签名、日期或题记 |
| 其他自定义描述 | 直接显示该描述 | 其他需要用户填写的内容 |

相同文字描述只会生成一个输入项，但输入时会同时替换所有同描述图层。如果文字描述包含“诗词”、“正文”、“内容”或“文案”，页面默认使用多行输入框。

## 通用文字输入规则

以下规则适用于所有读取文字属性的 H5 页面，包括百家姓、十二生肖、原图定制、音乐款定制、诗词定制和人像款定制。每个文字图层独立读取自己的配置，不同文字可以使用不同限制。

启用 H5 用户输入规则后，页面会统一执行英文限制、符号限制、
主动换行、单行字符限制、最大字符限制和最大行数。中文及非 ASCII 字符计 2，
ASCII 字符计 1，换行符不计入总字符数。即使关闭主动换行，设置单行限制后仍会
由系统自动换行；最大行数为 1 时固定使用单行输入框。

### 符号和 Emoji

“支持符号和 Emoji”默认关闭。只有明确开启后，H5 用户输入才会保留标点、特殊符号和 Emoji。

| 配置 | H5 输入结果 |
| --- | --- |
| 未开启 H5 用户输入 | 不执行输入限制，保留用户输入。 |
| 启用 H5 用户输入，符号开关关闭 | 只保留文字、数字和空白，过滤标点、特殊符号和 Emoji。 |
| 启用 H5 用户输入，符号开关开启 | 保留标点、特殊符号和 Emoji，再执行长度与行数限制。 |
| 仅支持英文 | 只保留英文可打印字符；Emoji 始终会被过滤。 |

例如输入 `中文 A1!😀`：符号开关关闭时得到 `中文 A1`；符号开关开启时完整保留。
运维配置姓名、日期和短标题时建议保持关闭；只有模板确实需要标点或 Emoji 时再开启。

输入规则按“字符范围和符号过滤 → 最大内容长度 → 自动换行 → 最大行数”的顺序执行。
长度限制按过滤后的内容计算，避免已经禁止的符号占用可输入长度。

### 单行短文本

姓氏、姓名、日期和短标题不希望换行时，应在文字属性中将“显示方式”设置为
`单行适配`，不要通过“关闭主动换行 + 单行长度”猜测显示行为。

| 配置项 | 百家姓“姓”的建议值 | 说明 |
| --- | --- | --- |
| 显示方式 | `单行适配` | 保持模板文字区域宽度和中心点。 |
| 最大内容长度 | `4` | 中文计 2，因此可输入“欧阳”两个中文。 |
| 最小字号 | 按模板效果填写 | 不填写时默认为模板字号的 60%。 |

单行适配会先使用模板原字号。内容放不下时自动缩小字号；达到最小字号仍放不下时，
允许文字超出模板区域，但不会换行或裁切。用户从“欧阳”改回“王”时会恢复模板原字号。

图层缩略图出现“单行适配”标记，表示该文字已配置此显示策略。运维只需配置显示方式、
最大内容长度和最小字号，不需要同时填写单行长度与最大行数。

### 仅支持竖行

只允许 H5 用户输入按一列从上往下展示时，开启文字属性中的 `仅支持竖行`。该开关只在
“启用 H5 用户输入”开启时生效，会自动关闭用户主动换行，保持模板字号和文字中心，
并禁止文字换到第二竖列。运维只需填写“最大内容长度”，不需要配置单行长度、最大行数
或最小字号。

中文及非 ASCII 字符仍计 2，英文计 1。例如最多允许 4 个中文时，“最大内容长度”填写
`8`。图层缩略图出现“竖行”标记，表示 H5 替换文字时会强制使用单列竖行约束。

## 人像款定制配置

人像款页面的背景图、可定制文字和图片适配规则与诗词定制相同，主图标记使用人像页的专用可选值。

### 可替换人像

| 配置位置 | 可用值 |
| --- | --- |
| 图片用途 | `AI 可变图` |
| 图片描述 | `人像替换`、`人像定制`、`AI主题`、`原图替换`或`原图定制` |

建议优先使用图片用途 `AI 可变图`，图片描述用于补充业务语义。如果一张图片同时符合用途和描述，页面只会替换一次。

### 人像文字

| 文字描述 | H5 页面显示的名称 |
| --- | --- |
| `文本替换` 或 `文案替换` | 定制文案 |
| `主标题` | 人像标题 |
| `副标题` | 副标题 |
| `落款` | 落款 |
| 其他自定义描述 | 直接显示该描述 |

## 背景、遮罩和打印区域

### 背景图

固定背景可以保持普通图片，不需要添加业务标记。只有诗词和人像页需要让用户切换背景时，才必须将图片用途设置为 `背景图`。

背景图建议铺满画板、放在底层、锁定图层并开启点击穿透，避免编辑其他内容时误选背景。

### 遮罩图

生产需要使用遮罩时，将图片用途设置为 `遮罩图`。遮罩图不会成为用户可替换图片，它用于展示成品遮挡关系和辅助识别打印区域。

### 打印区域

需要产品图时，应在编辑器的画布工具中创建打印区域，或根据遮罩图自动识别后再手动调整。不要自己新建普通矩形后只把图层名改成“打印区域”。

H5 保存时始终生成整张预览图。模板存在打印区域时，还会额外生成产品图。

| 输出图片 | 范围 | 背景图 | 遮罩图 |
| --- | --- | --- | --- |
| 预览图 | 整个画板 | 包含 | 包含 |
| 产品图 | 打印区域 | 不包含 | 不包含 |

## 通用配置流程

1. 在编辑器中打开正确的后台模板。
2. 确认画板尺寸、图层顺序和每张图片的显示范围。
3. 在图层面板打开目标图层的“属性”。
4. 按本手册对应页面填写图片描述、文字描述或图片用途。
5. 点击“保存配置”，对所有业务图层逐个完成配置。
6. 点击编辑器“立即保存”，保存整个模板。
7. 用对应 H5 页面和模板 ID 打开预览，按页面验收项逐项检查。

## 上线验收清单

| 检查项 | 合格标准 |
| --- | --- |
| 页面类型 | 商品配置的 H5 页面与模板类型一致。 |
| 模板 ID | 页面能正常加载，不提示缺少或无效的模板 ID。 |
| 画布显示 | 画板完整显示，图片顺序与编辑器一致，没有裁切、闪烁或空白图层。 |
| 文字替换 | 修改每个输入项时，只有对应描述的文字更新。 |
| 图片替换 | 替换后图片的位置、图层层级和显示范围符合模板预期。 |
| 字体 | 模板中的特殊字体能加载，刷新页面后字体不变。 |
| 背景和遮罩 | 背景在底层，遮罩在预期层级，普通操作不会误选它们。 |
| 打印区域 | 位置和尺寸正确，产品图不包含背景和遮罩。 |
| 保存 | 点击“立即购买”后有加载状态，保存成功后正常返回商品流程。 |

## 常见配置错误

| 现象 | 优先检查 |
| --- | --- |
| 输入文字后画布不变 | 是否只修改了图层名；文字描述是否与本手册完全一致。 |
| 上传图片时提示未配置标记 | 目标图片的图片描述或图片用途是否正确，属性是否已保存到模板。 |
| 生肖选中后不显示图片 | 是否存在对应生肖汉字的图片描述，尤其检查默认的 `鼠`。 |
| 诗词或人像页没有背景选项 | 背景候选图是否由业务页面传入，模板背景图的图片用途是否为 `背景图`。 |
| 诗词或人像页没有文字输入项 | 目标文字图层的文字描述是否为空。 |
| 保存后没有产品图 | 模板是否通过画布工具创建了真正的打印区域。 |
| 保存后没有返回小程序 | 业务页面是否传入正确的返回路径，当前页面是否在小程序 web-view 中打开。 |
